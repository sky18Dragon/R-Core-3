## 构建入口

激活 [固定SDK](DEVELOPMENT.md) 后：

```sh
python3 build.py --board read_pico --step firmware \
  --read-pico-factory-diagnostic --read-pico-photoframe-integration
```

独立输出 `build-read-pico-integration/` / `.cache/sdkconfig.read_pico-integration`。必须指定Read Pico和factory配置，与display/storage互斥；禁止flash/monitor/erase/fullclean及额外参数。普通诊断默认关闭集成选项，仍不挂载SD、不进入业务。

此配置保留PhotoFrame的真实 `main.c`、Wi-Fi/Web、上传/相册、图片处理、轮播及OTA源码。构建将原 `app_main` 仅重命名为 `photoframe_app_main`，并通过有副作用的volatile函数指针保留链接；专用 `read_pico_integration_entry.c` 只报告INTEGRATION_ONLY，不调用产品入口、不初始化板卡、NVS、存储、显示或网络。主机测试实际调用该入口，并确认产品调用次数为零。

使用与已验收显示诊断相同的精确684行外层覆盖和PERF/cache配置；厂家固定子模块不改。不调VCOM、gamma、PCLK或Flash/PSRAM频率。此时共享嵌入Web/splash资源只作为编译输入，不把已有资源尺寸或链接成功计为新板开机画面验收。factory布局不提供完整产品OTA条件；不得照用编译器打印的通用全量烧写命令。

## 业务安全适配

- NVS：Read Pico启动先初始化NVS，错误直接返回，不启动板卡/存储/配置业务。`nvs_bootstrap.c`在新板构建中直接排除自动擦除代码，即使未来误传legacy恢复选项也不能启用；Web整分区恢复出厂接口也返回501/NOT_SUPPORTED而不擦除或重启。原板保留原有恢复策略。初始化成功不代表旧Demo命名空间已完成迁移，产品配置仍会写NVS，因此保持运行门禁。
- 存储：`storage_init`只调用唯一 `read_pico_sd_mount`，失败保留原错误、不切换LittleFS/MemFS。挂载后查询重新读CD；异常/拔卡不再报告可用持久存储，也不隐式卸载。`storage_unmount_checked`按所有权清理失效介质，失败不发布未挂载或允许新挂载。Read Pico产品格式化返回NOT_SUPPORTED，wifi.txt读取先检查介质有效性。文件消费者关闭/并发和实际卡供电仍需后续集成验收，详见 [SD说明](READ-PICO-STORAGE.md)。
- 路径：显示状态和last_image容量统一为512字节含NUL，与最长511字符的现有轮播路径一致；文件及所有流式发布/快照/失败回退路径必须在刷新之前检查容量，超长拒绝、不截断、不发布。不会据此宣称所有上游HTTP/相册API都支持511字符，也没有自动迁移历史已截断记录。
- 睡眠：未验收PMU睡醒之前，Read Pico睡眠入口直接返回，不先关Wi-Fi/卸载SD，也不落入原板ESP原生deep sleep。按键mask由便携有界函数生成，未接线负值及>=64值返回零，避免未定义位移。此为禁用保护，不是低功耗实现。
- 集成编译发现的O2字符串告警已在调用处修复：HTTP缩略图同容量完整复制，配网字符串保持终止，AP支持带显式长度的32字节SSID；不放宽编译检查。JPEG分配失败日志采用size_t格式。
- 文件JPEG：Read Pico分块读取压缩源，≤5MiB缩放RGB和有界EXIF 1–8映射，再复用居中Cover/灰阶/抖动；源/EOF/关闭确认后才开始显示、不删除原片。关闭失败原子锁存SD退出；主机433项及5原片业务检查通过、集成镜像cf0e40bc…/1,978,080字节仅编译，不计ROM/实屏或内存峰值。内存JPEG/PNG与其他消费者关闭/并发尚未完成，见 [照片处理](READ-PICO-PHOTO.md)。
