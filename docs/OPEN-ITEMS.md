## 首版范围分层

这是对现有 TODO 的开发划分，不表示用户新增承诺；暂不擅自选择轮播间隔或续航数字。

| 范围 | 功能 | 完成定义 |
| --- | --- | --- |
| P2 显示基础 | 板级启动、只读 VCOM、GC16、4bpp 映射 | 标准图案与照片在本版实屏通过 |
| P3 相框 MVP | SD、Wi-Fi/Web 上传、相册、等比 Cover、选图/轮播 | 无相机、无云依赖也能完成上传到实屏 |
| P4/P5 第一阶段 | 触摸、PMU 睡眠/定时唤醒、错误恢复；上游 Web/REST/URL/OTA 回归 | 明确支持项与限制，按各项证据验收 |
| 性能优化 | 大图流式解码、更多缓存/缩略图策略 | 先测上游现有能力，确有缺口再增加 |
| 第二阶段 | GR 发现、连接、下载、预约同步 | 第一阶段通过后单独验证 |

“保留上游能力”不等于新板全部已兼容。尤其 OTA 要在分区迁移确定后验证；触摸和 PMU 需要新板专属实现。上游的电流、续航和支持卡容量不得当作本项目已达指标。

## 图片测试资料

已有三张私人样片及历史预览位于外部测试资料目录，可做相同构图的对照；不公开提交。新增标准样本由开发者生成，源文件附摘要、格式、像素尺寸、文件大小、EXIF 方向和预期结果。

| 组别 | 样本/检查 | 要求 |
| --- | --- | --- |
| 映射 | 白黑、16 阶、奇偶像素、四角文字/网格 | 灰阶顺序、无 nibble/行错位、无镜像 |
| 构图 | 横图/竖图/方图、EXIF 1–8 | 等比 Cover、居中、不拉伸，原文件不变 |
| 解码 | baseline/progressive JPEG、PNG/透明图、大图 | 分别记录支持/拒绝和内存峰值，拒绝不崩溃 |
| 异常 | 截断、损坏、超限、分配失败 | 有界退出，旧图/原文件保留，不发布半成品 |
| 介质 | 无卡、拔卡、满卡、重启、写中断 | 不自动格式化，有可说明的恢复路径 |

容量、时延与功耗先记录实际基线，再设置验收阈值。既定长稳次数属于测试计划，不等同于质量保证或用户续航要求。
