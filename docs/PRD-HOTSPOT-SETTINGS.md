# 产品设计：热点传图与屏上设置

状态：第 9 节决策已由用户确认（2026-11-01），任务已拆入 [路线图](ROADMAP.md) R2。S1 预研完成（结论见 6.1）；H1 已实现并于 2026-11-02 真机测试通过主要项，与本文的差异及真机结果见第 11 节；H3 已在软件实现（未上板），见第 12 节；H2 未开发。不属于 R1，不改变 [TODO](../TODO.md) 的 R1 范围；本文所有“现状”均来自 2026-11-01 对源码与文档的只读核对，未经真机验证的部分已注明。

## 1. 需求与问题

| 编号 | 用户原话 | 产品化表述 |
| --- | --- | --- |
| A | 墨水屏可以进入热点模式，在没有网络的情况下让手机连接传输照片 | **热点传图**：相框自建 Wi-Fi，手机直连后用现有网页上传、管理、显示照片，全程不需要路由器和外网 |
| B | 可以在墨水屏中设置网页的系统设置功能 | **屏上设置**：不借助手机/电脑，直接在相框上用触摸键完成常用系统设置（含开关热点） |

两者是一个闭环：没有网络时手机打不开网页，所以“开启热点”这一步必须能在相框本机上完成；屏上设置就是这个入口，同时承接其他“离线也要能改”的设置。

> 需求 B 即“把网页系统设置中的常用项搬到相框屏幕上操作”（D1 已确认）。

### 典型场景

1. **出门/展会/民宿**：没有可用 Wi-Fi 或不方便配网，想把手机里几张照片放到相框上。
2. **送礼/长辈家**：家里没有路由器或密码不知道，收礼人只有手机。
3. **家里路由器坏了/换了**：相框连不上原网络，仍想换照片，或想先传图、以后再配网。
4. **快速调整**：手边没开电脑，想关掉轮播、改轮播间隔、看一下 IP、把画面转 180°。

### 不解决的问题（本期非目标）

- 不做手机 App，不做蓝牙传图；传输仍走浏览器网页。
- 不做相框作为路由器转发外网（无 NAT/上网共享）。
- 屏上设置不追求与网页 1:1；复杂、低频、需要键盘输入的设置仍只在网页（见 4.3）。
- 不在屏上提供格式化 SD、恢复出厂、擦除 NVS 等破坏性操作（项目规则禁止自动执行，屏上误触风险高）。

## 3. 产品方案总览

```
            ┌──────────── 相框本机 ────────────┐
 按中键 ──▶ │ 屏上设置菜单（一屏）              │
            │  ▸ 热点传图  ← 第一项，最常用     │──开启──▶ 热点信息页（二维码①连Wi-Fi ②开网页）
            │  ▸ 轮播 / 间隔                    │                    │
            │  ▸ 画面旋转 / 清屏                │          手机扫码连接 → 浏览器打开 192.168.4.1
            │  ▸ 网络信息 / 设备信息            │                    │
            │  ▸ 语言                           │          现有网页：上传 / 相册 / 显示 / 系统设置
            └───────────────────────────────────┘                    │
                                                         结束热点（手机/屏上/超时）→ 回到原网络模式
```

核心原则：

1. **网页能力不重做**：热点模式下手机看到的就是现在的网页，上传、相册、处理参数全部复用；新增的只是“另一种连上相框的方式”。
2. **热点按需开启、自动关闭**：默认不常开，降低暴露面和功耗。
3. **屏上只做离线必需和高频小改**：其余去网页。
4. **一屏菜单 + 中键进入、两侧键移动、中键确认**：适配 2 秒全刷。

## 4. 功能设计

### 4.1 热点传图

#### 入口

| 入口 | 说明 |
| --- | --- |
| 屏上菜单第一项“热点传图” | 主入口，任何网络状态都可用 |
| 长按中键 3 秒 | 快捷开/关热点，无需进菜单（误触成本低：开启只显示二维码，关闭不影响数据） |
| 网页“系统设置 → 设备与网络 → 热点传图” | 已在家庭网络时也可预先开启，或修改热点设置 |
| 首次开机 / 家庭 Wi-Fi 连不上 | 自动开启同一个设备热点，网页里可选“先用热点传图”或“连接家庭 Wi-Fi”（见 4.1 首次开机与配网合并） |

#### 连接流程（目标：首次 ≤ 60 秒，再次 ≤ 20 秒从开热点到看到网页）

1. 用户开启热点 → 相框全刷一次，显示**热点信息页**（横屏布局）：
   - 左：二维码①“扫码连接相框 Wi-Fi”（`WIFI:T:WPA;S:<SSID>;P:<密码>;;`，iOS 相机与安卓相机均可识别）
   - 右：二维码②“连上后扫码打开网页”（`http://192.168.4.1`）
   - 下方大字：Wi-Fi 名、密码、网址；剩余时长“无人连接 10 分钟后自动关闭”；操作提示“中键：结束热点”
2. 手机扫码① → 系统提示加入网络 → 加入。
3. 手机扫码② 或手动打开浏览器输入 `192.168.4.1` → 进入现有网页首页（上传页）。
4. 上传照片、选择显示；网页顶部出现热点状态条：“热点传图中 · 已连接 1 台 · [结束热点]”。
5. 结束：网页按钮、屏上中键、或超时自动关闭 → 相框回到进入热点前的网络模式（若之前连着家庭 Wi-Fi，则自动重连）。

#### 网络名与密码

- SSID：沿用 `PhotoFrame - xxxxx`（设备唯一后缀）；配网与传图共用这一个热点（D3）；用户可在网页改为自定义名称（≤32 字节）。
- 加密：**WPA2-PSK，必须有密码**。首次开启时随机生成 8 位易读密码（去掉 0/O/1/l/I 等易混字符），保存在 NVS，之后保持不变，手机会自动记住、再次开启无需扫码。
- 屏上菜单与网页均可“更换热点密码”（重新随机生成）；网页可自定义（8–63 位）。
- 网页访问密码（已有功能）若开启，在热点模式下同样生效。

#### 热点与家庭 Wi-Fi 的关系：二选一（D2 已确认）

开热点时断开家庭 Wi-Fi，结束后自动重连；热点期间家里其他设备访问不到相框。复用现有 AP 租约（AP 期间普通连接本就不抢占）。不做 APSTA 并存：ESP32 的 AP 信道会被迫跟随路由器，家庭网络断开重连会扰动热点，状态组合翻倍。

#### 关闭规则

- 无客户端连接持续 **10 分钟** 自动关闭（网页可选 10 / 30 / 60 分钟 / 不自动关闭；电池供电时不提供“不自动关闭”）。
- 有客户端连接或有上传进行中时不计时；上传中禁止关闭（屏上/网页关闭按钮给出“正在上传，完成后自动结束”）。
- 开启热点期间不进入电池睡眠；睡眠变体中热点关闭后再按原策略计时。
- 关闭后屏幕：若热点信息页仍在屏上，换回当前照片；若期间已换图则不额外刷新。

#### 屏幕显示策略

- 进入热点时显示热点信息页；之后**任何显示操作（网页显示照片、上传后显示、触摸换图、轮播）都会替换它**，热点继续运行。需要再看二维码时从菜单“热点传图”进入。
- 轮播在热点期间照常运行，但**热点信息页显示后的首个轮播周期跳过**，避免用户还没扫码二维码就被换掉。
- 墨水屏断电也保留画面：热点信息页包含明文密码，结束热点时必须刷回照片，不能把密码留在屏上（这也是“关闭后换回照片”的原因）。

#### 手机兼容（需真机验证，见第 8 节风险）

- **不弹 captive portal 小窗（D4 已确认，配网场景同样适用）**：热点模式下设备对系统联网探测地址返回“联网正常”的应答，手机不会弹出功能受限的认证小窗（iOS 小窗里上传多图、HEIC 转换不稳定，关闭小窗还可能断开 Wi-Fi）。用户通过二维码②或手动输入网址进入完整浏览器。
- 安卓“此网络无法访问互联网，是否保持连接”提示：信息页与网页说明“选择保持连接”；若部分机型仍走移动数据导致打不开 `192.168.4.1`，提示“暂时关闭移动数据”。
- 网址统一用 IP，不依赖 `.local`（安卓浏览器普遍不解析 mDNS）。

#### 离线校时

热点模式无法 NTP。网页在热点模式下打开时，若设备时间与手机时间相差 > 2 分钟，顶部提示“相框时间不准，[用手机时间校准]”，点击后写入设备时间（需新增写时间接口，见第 6 节）。影响轮播计划/定时等依赖时间的功能。

#### 首次开机与配网合并（D3 已确认）

现状：首次开机或家庭 Wi-Fi 恢复失败时，设备开启**开放**配网热点，只提供配网页面。改为只有一个“设备热点”：

- **加密**：配网也使用 WPA2 与上文同一组名称/密码；首次开机时生成随机密码，引导页的 Wi-Fi 二维码改为带密码（`WIFI:T:WPA;...`），并显示明文密码。不再存在开放热点。
- **完整网页**：设备热点始终提供完整网页与 API，配网只是“系统设置 → 设备与网络”里的一个小节；原 `/provision` 配网页保留为该小节的跳转，不再单独维护一套页面。
- **首次开机**：屏幕显示热点信息页（同 5.1，标题“欢迎使用”）；手机打开网页后先看到二选一引导：
  - **连接家庭 Wi-Fi**：扫描、输入密码、先试连再保存（沿用现有候选测试与检查式整组保存），成功后结束热点、重启进入家庭网络，屏上显示 `http://名称.local` 与 IP 二维码（现有配网完成页）。
  - **先用热点传图**：直接进入上传页；以后可在网页或屏上菜单随时配家庭 Wi-Fi。选择此项后记为“仅热点”网络模式，重启后不自动开热点，需屏上开启（见 4.1 入口）。
- **家庭 Wi-Fi 连不上**（原恢复配网路径）：自动开启设备热点，网页顶部提示“无法连接家庭 Wi-Fi「名称」· [重新配网] [先传图]”；传图照常可用。家庭 Wi-Fi 恢复（后台按原退避策略重试，需在 AP 空闲时进行）或用户重新配网后结束热点。仍不擦除已保存凭据（沿用新板现行契约）。
- **自动关闭例外**：首次开机及家庭 Wi-Fi 连不上而自动开启的热点，在 USB 供电时不自动关闭（否则用户无法再配网）；电池供电时 10 分钟无连接关闭，按中键可重新开启。

此项改动上游配网流程（`wifi_provisioning*`、`splash_screen`、`main` 中的恢复路径），属于网络暴露与 OOBE 行为变更，需按第 7 节逐项真机回归。

### 4.2 屏上设置菜单

#### 交互模型（适配 GC16 全刷约 2 秒）

| 操作 | 菜单外（看照片） | 菜单内 |
| --- | --- | --- |
| 左/右触摸键 | 上一张/下一张（现状） | 光标上移/下移 |
| 中键短按 | **打开菜单** | 确认/切换当前项 |
| 中键长按 3 秒 | 开/关热点 | 返回照片 |
| 滑动 | 换图（现状） | 不响应（避免误操作） |
| 点击屏幕菜单项 | — | 直接选中并确认（触摸校准通过后启用；未校准前仅用按键） |

- **一屏显示全部菜单项**，光标移动用局部重绘；若局部快刷能力未就绪（见 6.1），光标移动也需全刷——因此菜单项控制在 7 项以内，常用项排在最前。
- 菜单 **30 秒无操作自动返回照片**，不改变任何设置。
- 每项“即改即生效”，不设保存按钮；改动立即写入并在该行显示新值。危险操作不放在屏上，因此无需二次确认弹窗。
- 菜单打开期间轮播暂停，返回照片后重置计时。

#### 菜单内容（建议首版 7 项）

| # | 项 | 屏上操作 | 对应网页分组 |
| --- | --- | --- | --- |
| 1 | 热点传图：关闭 / 开启中 | 确认 = 开启并显示信息页；开启中再确认 = 结束 | 设备与网络（新增） |
| 2 | 轮播：开 / 关 | 切换 | 图片设置 → 自动轮播 |
| 3 | 轮播间隔：5 分钟 | 循环切换预设 1 / 5 / 15 / 30 分钟、1 / 3 / 6 / 12 / 24 小时 | 图片设置 → 自动轮播 |
| 4 | 画面旋转：0° / 180° | 切换并立即重绘当前照片 | 屏幕 |
| 5 | 清屏除残影 | 执行一次刷白再重绘 | 屏幕（新增动作） |
| 6 | 网络与设备信息 | 进入只读信息页：网络模式、家庭 Wi-Fi 名、IP、网页地址二维码、SD 剩余空间、照片数、固件版本；附“更换热点密码” | 关于 / 设备与网络 |
| 7 | 语言：中文 / English | 切换（屏上与网页共用设置） | 语言 |

电池睡眠变体额外显示“电池睡眠：开/关”（与网页“电源”分组同一设置），默认本地相框不显示该项。

### 4.3 屏上 vs 网页 能力矩阵

| 设置 | 屏上 | 网页 | 理由 |
| --- | --- | --- | --- |
| 开/关热点、换热点密码 | ✓ | ✓ | 离线入口必须在屏上 |
| 热点名称/自定义密码/自动关闭时长 | — | ✓ | 需要键盘输入 |
| 家庭 Wi-Fi 选择与密码、静态 IP、DNS、NTP | 只读显示 | ✓ | 需要键盘输入；扫描列表在墨水屏上体验差 |
| 重新配网 | — | ✓（设备与网络） | 配网与传图已合并：屏上开热点后在网页配；屏上不提供“清除家庭 Wi-Fi” |
| 轮播开关/间隔 | ✓ | ✓ | 高频小改 |
| 画面方向（横/竖）、旋转 | 仅旋转 0°/180° | ✓ | 横竖切换影响已处理的图片，留在网页 |
| 时区、时间 | 只读 | ✓（含手机校时） | 列表过长 |
| 灰阶/调色校准、图像处理参数 | — | ✓ | 需要预览与滑杆 |
| 设备名、网页访问密码 | 只读设备名 | ✓ | 需要键盘输入 |
| 配置备份、日志、格式化 SD | — | ✓ | 破坏性或需文件交互 |
| HA、AI 等实验功能 | — | ✓ | 非本地相框范围 |
| 语言 | ✓ | ✓ | 两端共享 |

## 6. 技术方案要点与依赖

供工程拆解，结论以源码核对和真机验证为准。

### 6.1 显示：局部快刷（屏上菜单体验的前置）

- 现状只有 GC16 全刷，菜单每次光标移动闪 2 秒，可用但体验差。
- **技术预研 S1**：核对厂家波形是否提供 DU/A2 等快刷模式及其局部窗口刷新能力；若可用，菜单光标与数值变化用局部快刷，进入/退出菜单与热点信息页用 GC16。
- 预研不通过时降级：菜单保持一屏、光标移动全刷，并把常用项放前两位；不阻塞热点传图本身（热点只需一次全刷显示信息页）。
- 遵守项目规则：厂家波形/驱动保持原样，差异在外层适配；不得把 GC16 偷换成 DU。
- **S1 结论（2026-11-01，只读源码核对，未上板）：可行。** 我们已在用的 `E0470_WAVEFORM` 同时带 20 相阈值 DU（目标 0–7→黑、8–15→白）和 37 相 GL16（`third_party/read_pico_firmware/components/e0470_epaper_waveform/include/e0470_epaper_waveform.h`）；同一 epdiy 提供 `epd_hl_update_area` / `epd_hl_update_area_full`，厂家阅读、首页与按键界面正是用 `update_display_area_with(hl, &E0470_WAVEFORM, MODE_DU 或 MODE_GL16, area)` 做局部刷新（`main/display.c`、`main/apps/app_book.c`、`main/apps/app_key.c`）。H2 菜单的光标与数值用 DU 局部刷新、进出菜单用 GC16；我们的驱动目前只暴露 GC16 全屏入口，需在外层适配新增一个局部刷新入口（不改厂家代码），速度与残影需实机测。

### 6.2 屏上文字渲染

- **推荐**：构建时把中英文菜单、热点信息页的固定文字预渲染为位图资源（沿用 splash 的 EPDGZ 方式），运行时只叠加：二维码（已有）+ 小型 ASCII 位图字体（数字、字母、`.:-/`，用于 IP、SSID、密码、时长）。体积小、无需完整中文字库。
- 限制：家庭 Wi-Fi 名或设备名含中文/emoji 时，屏上显示为“（含非 ASCII 字符，请在网页查看）”。
- 备选：引入 LVGL + 子集中文字体，灵活但增加 Flash/PSRAM 与集成成本，首版不建议。

### 6.3 热点服务

- 复用 `wifi_provisioning_ap` 的 AP 启动/停止、租约与检查式停机，把它改为唯一的“设备热点”：WPA2-PSK、注册**普通网页与 API 路由加配网路由**，DNS 只为系统探测域名应答本机地址并返回“联网正常”内容（替换现有把所有请求重定向到 `/provision` 的 captive portal 行为）。
- 配网保存、候选测试、`provisioning_session` 完成门禁继续沿用现行契约；“仅热点”模式下没有配网会话，等待配网完成的启动分支不能阻塞相框其他服务。
- 与普通 HTTP 服务、轮播、显示、上传共用现有资源控制；热点开启/关闭期间的 HTTP 停启要有明确所有权，避免 AP 与 STA 两套服务同时持有端口。
- 新增 API（草案）：`GET/POST /api/hotspot`（状态、开关、名称、密码、自动关闭时长、连接数）、`POST /api/time`（写入手机时间）。local-frame 的“拒绝未验收入口”策略对这些新接口需显式放行并有主机测试。
- 新增 NVS 键：热点名称、热点密码、自动关闭时长、上次网络模式。不擦除、不迁移已有键。

### 6.4 屏上菜单

- 新增“菜单”状态在 `read_pico_touch_nav` 之上：菜单外维持现有换图语义，中键事件进入菜单状态机；菜单的状态机、选项循环、超时逻辑做成可主机测试的便携模块，板级渲染放在适配层。
- 所有画面经现有显示管理器统一入口，刷屏期间只保留最后一次请求（沿用现有触摸策略）。
- 菜单设置项写入走已有检查式配置保存（轮播、旋转、语言），与网页共享同一份配置，网页刷新后可见屏上的改动。

## 7. 验收标准

功能（真机，T3 风格一次完成）：

1. 无路由器环境下：屏上开启热点 → iPhone（iOS 最新正式版）与一台安卓机分别扫码连接 → 浏览器打开网页 → 各上传 3 张（含 HEIC）→ 显示成功；首次全流程 ≤ 60 秒，手机已记住网络时 ≤ 20 秒。
2. 热点为 WPA2，错误密码无法加入；SSID/密码与屏上一致；更换密码后旧密码失效。
3. 无客户端 10 分钟自动关闭；上传进行中不关闭；关闭后屏幕回到照片、屏上不残留密码；之前连着家庭 Wi-Fi 时 60 秒内自动重连且网页可访问。
4. 热点期间轮播、触摸换图、网页显示正常；信息页后首个轮播周期被跳过。
5. 屏上菜单 7 项逐项生效，网页刷新后显示相同值；30 秒无操作退出；长按中键开/关热点。
6. 离线校时：热点模式下网页一键校时后设备时间误差 < 5 秒。
7. 重启保持：热点名称/密码/时长、屏上改过的设置重启后保留；已配家庭 Wi-Fi 或“仅热点”模式重启后热点默认关闭（不自动开启）。
8. 首次开机（需清空凭据的测试条件，按项目规则不自动擦 NVS，由你决定方法）：屏上显示带密码二维码，扫码加入 → 网页二选一 → 分别走通“连接家庭 Wi-Fi”（错误密码被拒、正确密码保存后重启上线）和“先用热点传图”（直接上传显示）；全程无开放热点。
9. 家庭 Wi-Fi 连不上：关掉路由器后设备自动开启设备热点，网页提示可重新配网；传图可用；路由器恢复后设备回到家庭网络，凭据未被擦除。

失败与安全：

- 热点开启时拔 SD、上传超限、坏图：沿用现有失败反馈，热点不崩溃。
- 热点 AP 启动失败：屏上提示“热点开启失败”，回到原网络模式，不重启、不擦凭据。
- 屏上任何操作都不会格式化 SD、擦除 NVS、修改 VCOM。
