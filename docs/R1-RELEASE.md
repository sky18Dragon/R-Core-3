# R1 本地相框：交付说明

适用设备：小纸 Pico（Read Pico，ESP32-S3，16MB Flash / 8MB PSRAM，1216×684 16 灰阶电子纸）。R1 范围：网页上传图片 → 墨水屏显示 → 自动轮播 → 重启保持；USB 供电、常在线、不睡眠、本地 SD 存储。逐项证据见 [验证记录](VALIDATION.md)，启动路径见 [R1 启动路径](R1-RUNTIME.md)。

## 2. 构建

按 [开发说明](DEVELOPMENT.md) 激活固定 SDK（必须设置 `IDF_PYTHON_ENV_PATH`，否则 idf.py 会拒绝），然后：

```bash
python build.py --board read_pico --step firmware --read-pico-local-frame
```

输出在 `build-read-pico-local-frame/esp32-photoframe.bin`。提交前按 [测试策略](TESTING.md) 跑 T1：

```bash
scripts/test_quick.sh --asan --firmware
```

## 3. 部署（只写应用分区）

沿用本机已核验的 factory 分区表（NVS `0x9000`、PHY `0xe000`、factory `0x10000`/4MB、内部 FAT `0x410000`）。只写 `0x10000`，**不写** bootloader、分区表、NVS、PHY、storage，不要使用构建器打印的完整烧写命令。每次烧写前需要设备所有者确认镜像与范围。

1. 只读核对芯片、Flash 和分区表（分区表 SHA256 应为 `f078383d1525d206e6f7eb4aea29af811fc36a89e195d222d9256fffe6892d20`）：

```bash
python -m esptool --chip esp32s3 --port /dev/cu.usbmodem2101 --no-stub --after no-reset chip-id
```

```bash
python -m esptool --chip esp32s3 --port /dev/cu.usbmodem2101 --no-stub --before no-reset --after no-reset read-flash 0x8000 0x1000 pt-before.bin
```

2. 只写应用：

```bash
python -m esptool --chip esp32s3 --port /dev/cu.usbmodem2101 --no-stub --before no-reset --after no-reset write-flash --flash-mode keep --flash-freq keep --flash-size keep 0x10000 esp32-photoframe.bin
```

3. 全长回读并比对（长度用镜像实际字节数），再读一次分区表确认与写前一致：

```bash
python -m esptool --chip esp32s3 --port /dev/cu.usbmodem2101 --no-stub --before no-reset --after no-reset read-flash 0x10000 1958448 app-readback.bin
```

```bash
cmp esp32-photoframe.bin app-readback.bin
```

4. 复位启动（打开串口即会触发 USB 复位），日志应出现 `SD card mounted successfully` 和 `got ip`。

串口名可能变化（如 `usbmodem101` / `usbmodem2101`），以 `ls /dev/cu.usbmodem*` 为准。

## 4. 首次使用

- **SD 卡**：必须是 FAT32（MBR 分区或无分区表）。exFAT 卡（64GB 以上卡出厂常见）会挂载失败并安全停止。固件不会格式化 SD 卡。
- **联网**：沿用 NVS 中已保存的 Wi-Fi；无凭据时可在卡根目录放 `wifi.txt`（第 1 行 SSID，第 2 行密码，第 3 行可选设备名），或连设备热点配网（热点配网本版未验证）。
- **开机**：先清屏为白，约 6–16 秒后网页可用。地址在启动日志里（本机为 `http://192.168.1.21`），也可试 `http://photoframe.local`。路由器不接外网也能用。
- **语言**：网页右上角按钮切换中文 / English，选择会被记住。

## 5. 网页操作

- **上传**：上传卡片里点击或拖入图片（JPG、PNG、HEIC、WebP、GIF、BMP），浏览器会按屏幕灰阶生成预览，确认后上传；图片转换在浏览器里完成，设备保存为 `.epdgz` 加缩略图。可以在预览旁调曝光、对比度、S 曲线等参数（各项都有中英文说明）。
- **相册**：新建/删除相册，勾选的相册参与轮播；点缩略图可在屏上显示，点删除按钮删图。
- **显示**：每次换图先刷白再从白 GC16 绘制，切图无残影，单次约 2 秒。
- **轮播**：设置 → 自动轮播。可选顺序或随机；计划用向导设置（全天按间隔或指定时间），或在“高级（Cron）”里直接写规则（如 `*/1 * *` 每分钟）。
- **灰阶标定**：设置 → 灰阶标定。本机已写入 16 码实测亮度（见下），一般不需要改；“显示色阶图”可在屏上显示 16 级原始灰阶用于复测。
- **配置备份**：设置 → 维护 → 导出 / 导入配置。

本机当前设置：灰阶 `black_y=0.028, white_y=0.645, gamma=0.79`，实测查表 `levels_y` = 0.028, 0.034, 0.042, 0.065, 0.095, 0.132, 0.201, 0.253, 0.337, 0.394, 0.470, 0.522, 0.581, 0.610, 0.643, 0.645；默认处理参数对比度 1.2，其余为默认；自动轮播关闭，随机顺序，每 12 小时。

## 7. 已知限制

- 热点配网未验证：网页改 Wi-Fi 会先试连并拒绝错误密码，需临时改路由密码或恢复出厂才能触发热点。
- 断电冷启动后的轮播未验证：拔 USB 时设备靠电池继续运行，并没有重启。
- 无卡时屏幕没有提示，看起来像“没反应”；需要看串口日志。
- 只支持 FAT32 卡，不支持 exFAT。
- 刷屏约 2 秒期间访问 SD 的网页请求会等待刷屏结束（单次上传最长实测约 6 秒），不再失败；此修复在 `13ebf199` 及之后的镜像中。
- 灰阶：厂家资料注明 16 个灰码约 11 级可分辨；查表数据来自手机拍照，属近似值。暗部和高光两端较挤，观感可用对比度或 S 曲线微调。
- 直接用接口上传时只接受 `.png` / `.epdgz` 原图加 `.jpg` 缩略图，单文件不超过 5MB；一般请用网页上传。
- 早先失败上传留下的约 224KB 隐藏临时文件仍在卡上（修复后不再新增）。
- 没有实时时钟：时间靠 NTP；无外网时按间隔轮播仍正常，但“指定时间”类计划会按未校准的时钟执行。
- 串口日志在重新打开端口后可能不再输出（不影响网页和轮播），调试时需复位再看。
- 本版关闭：网址图源、远程配置、Home Assistant、深度睡眠、OTA 升级、触摸。
- 网页上传卡片里的“格式化存储”按钮是上游功能，本板固件不支持格式化（接口返回失败），不会清空 SD 卡。
- 长时间运行后曾出现网络不可达：设备运行约 3 天时 192.168.1.21 不通、整个网段也扫不到，串口仍在输出；随后 USB 一度不枚举，重新插线并重刷后恢复。原因未查，长稳未验证。
