# 显示与交互实现原则

这是电子纸相框的实现约束，不是官网设计规范。产品交互以 `docs/PROJECT-SPEC.md` 为准。

- 2026-10-01 用户更新：照片等比 Cover 铺满 1216×684，按屏幕比例居中裁切，不拉伸、不新增纸边。Fit 保留为兼容工具／旧缓存路径，不代表当前展示要求。
- 16 灰阶照片使用 GC16；不做秒级轮播或照片渐变动画。
- 默认照片优先，菜单只在主动操作时出现；渲染与刷新分离。
- 上一张/下一张对应触屏和 KEY1/KEY3；KEY2 为操作菜单。
- 放下是展示决策，删除是本机副本操作；相机删除永不出现。
- 连续到达照片合并批次，只展示已提交的有效成品。
- NEW 在首次展示后变为 NORMAL，用户决策不会被下载/渲染回调覆盖。
- 当前 Demo 0 仅显示一次 SD 测试 JPEG，无产品菜单；影调、纸边和触摸阈值待样片/真机确认。
