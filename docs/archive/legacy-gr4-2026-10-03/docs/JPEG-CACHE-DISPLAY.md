## 行为与边界

`FRAME_JPEG_CACHE_DISPLAY=ON` 独立构建，只使用已有 `/sdcard/frame/jpeg-source-test` 和 `jpeg-cache-test`。先复用严格恢复：三源完整比较→正确绑定/相同有效双快照/空 journal/三 KEPT/照片序号1及global6→三生成缓存完整比较→源再比较→最终元数据复核。通过后释放1024字节内部DMA缓冲，再分配一份415872字节PSRAM暂存区。

每张显示前调用 `frame_cache_samples_jpeg_load`：固定 JPEG 缓存目录，拒绝缺失/错误/未知条目，核验绑定/双快照/索引/空日志，从 SD 读取完整缓存，比较头/长度/CRC/完整像素与可信参考，读后再核对元数据。输出指针不允许与任一参考重叠；false 时暂存区不可发布。共用加载实现保留旧 RAM 目录入口，但本专用固件禁止链接旧入口，不回落到 RAM 目录或嵌入像素。

只有通过的 SD 暂存字节才交给原有逐像素映射，1216×684、Cover layout=2，等比铺满/居中裁切、不拉伸；本版不重新裁切或解码。私有测试源此前已去除内置白框并缩小到1600边长，用户原片未改。原有像素映射、GC16、温度读取及锁定BSP/波形/校准不改。

复制后及读取显示电源/温度后均检查卡状态，再GC16刷新；前两张各停留30秒，第三张保留。不创建/补写/修复/cache checkpoint，不解码或操作相机，不格式化卡/擦NVS/写VCOM。读/分配/复制/卡/电源故障停止；未发起刷新时保留实际当前画面。刷新本身报错时画面可能部分更新，不保证原图完整保留；mask只计刷新返回成功。

预检查为一次有限时间窗，随后各张加载校验其缓存和库元数据；不会在每张之间重跑三JPEG源完整比较。没有并发写入任务，但不承诺对任意外部并发写者或检查后立即拔卡的原子快照/零竞态保证。本版无通用按钮交互，也不是正式自动轮播功能。
