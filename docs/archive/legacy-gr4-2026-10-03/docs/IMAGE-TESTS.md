输出：1216×684，Fit 保留完整构图及原图内置白边；正方形内容居中，左右各 266 像素外部白边。内部 g4 像素 415872 字节，加 PFG1 头总 415952 字节。16 级灰度、固定线性 profile 1，没有自适应提亮/裁剪；三张均使用了全部 16 档。天空和暗部仍需实屏评审，16 级量化与真实面板灰度不是同一件事。

每张均执行：

1. 完整校验/缩放解码并生成参考缓存。
2. 流式保存原 JPEG，故意拒绝 415872 字节缓存分配，确认返回 RENDER_PENDING 且未增加索引。
3. 关闭原输入和库，再打开库，仅从本地 PFU1/JPEG 恢复、重渲染并提交 NEW。
4. 持久化缓存与参考缓存逐字节一致；重复恢复过滤，三张全局提交序号为 3。
5. 双快照检查点并重开，恢复三张状态。

外部 SHA256 检查确认：三个原文件测试前后未变，每个入库 JPEG 副本与对应原文件完全一致。未提取或记录 EXIF 隐私字段。
