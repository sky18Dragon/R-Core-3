# GR IV GATT 只读诊断：便携核心

日期：2026-10-02。当前阶段仅实现元数据校验与值解析，没有无线 IO、连接、配对或运行时调用；不计 Gate A 通过。

后续进展：已增加无设备入口的有界会话与 NimBLE 身份读取操作层，主机34组/真实SDK组件编译通过，见 [操作层](GR4-GATT-IO.md)。尚无受控连接/退出 Owner 或真实读取；下文33组/2fc5a127…为便携核心阶段记录。

## 已实现

代码位于 `components/camera_gr4/gr4_gatt.c` 和 `include/gr4_gatt.h`，不依赖 ESP-IDF、堆分配或设备资源。

`frame_gr4_gatt_plan()` 接收当次完整发现的服务与特征，验证服务范围不重叠、声明/值句柄合法且归属一致、目标唯一、具有读取属性。仅输出 Manufacturer、Model、Firmware、Power、Operation Mode 五个动态值句柄，不使用参考代码的固定句柄，不包含序列号、SSID/口令或 CCCD。发现不完整、断连、连接世代为零、歧义、越界及缺失任一目标时，拒绝计划并清零输出。

列表可以无序，最多 16 个服务、128 个特征；v1.11 静态分析的 64 个自定义特征之外，为标准服务留有有界空间。超限必须停止，不静默截断。重复的目标服务拒绝选择，非目标服务允许相同 UUID，但仍须满足不重叠范围。具有写入属性的目标若同时可读，允许加入读取计划；本模块没有写入操作。

UUID 使用规范字符串对应的高位在前 16 字节，**不是 NimBLE/ATT 的小端内存布局**。适配层负责反转 128 位 UUID、将 16/32 位 UUID 展开为 Bluetooth Base UUID。服务/特征元数据发现不等于读取所有特征值。

## 值与证据等级

五项 UUID、归属、读取属性和最大长度来自本项目 `protocol/gr4-v111-bluetooth-firmware-analysis.md` §5.2–5.3；长度依次为 28、11、10、1、1 字节。Power / Operation Mode 单字节映射依据用户参考代码，见 [参考核对](GR4-BLE-REFERENCE-NOTES.md)，**尚未在本台相机/固件验证**。

- Power：0 → Off，1 → On，其余 → Unknown。
- Operation Mode：0 → Capture、1 → Playback、2 → BLE Startup、3 → Other、4 → Power-off Transfer，其余 → Unknown。
- 读取失败、空指针或非单字节值 → Invalid，并清除之前状态为 Unknown。Known 仅表示符合参考映射，不证明本机语义或允许 WLAN/唤醒操作。
- 三项文本只接受限额内非空可打印 ASCII，纯空格拒绝；保留原有空格，不猜测 NUL 填充、字符编码或型号别名。无兼容白名单，不把 GR IV / HDF / Monochrome 的实际字符串补造成已验证结果。文本异常时清零，原始响应不得直接写日志。

## 未来适配层必须承担的约束

核心接受的 `discovery_complete`、`connection_live` 和 `connection_epoch` 是调用方证据，不会自行检测无线状态；计划不是身份、认证或 IO 授权。

1. 独立诊断模式与 Observer 扫描互斥；有限候选、有限会话、独立截止、明确停止/清理。不得自动遍历连接附近设备。
2. 单执行者维护非零世代，核对连接句柄和世代；断连/重连立即使计划及旧状态失效，屏蔽晚回调；不得复用旧句柄或计数回绕造成旧世代复活。
3. 完整发现后，先受控读取 Manufacturer/Model/Firmware，分别核实型号与实际版本；未核实时不执行 Power/Operation Mode 读取。公共 UUID 和五句柄存在不证明 GR IV 身份。
4. 有界聚合分段 ATT 响应，成功且完整才解析；Manufacturer 最大 28 字节可能超过默认 MTU 的单次响应。权限错误、长度异常、超时、未知枚举均停止，不触发配对、唤醒或写入重试。
5. 不订阅通知（CCCD 写入）、不启动 SMP/bond 写入、不读私密字段、不发 Power/WLAN/ACK/拍摄/升级/删除。只读连接本身也可能影响待机，真机须记录是否唤醒与退出功耗，不能称完全无状态影响。
