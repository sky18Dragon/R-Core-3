# GR IV 只读诊断：受控候选选择与交接

日期：2026-10-02。当前完成便携选择器和 Owner 交接接口；**没有启用相机连接设备入口，仍为 compile-only**。唯一服务候选、人工确认和公开身份字符串都不是型号认证或配对证明。

后续进展：同SDK host扫描/停止证据与一次延迟激活、85秒全流程期限及扫描timer退休已实现，43组主机/实际SDK隔离ELF通过，见 [同SDK会话](GR4-SCAN-SESSION.md)。现场确认事件通道和设备入口仍未实现；以下41组及延迟激活缺口为选择器阶段记录。
## 已实现边界

`components/camera_gr4/gr4_target.c` 不依赖 ESP-IDF、不访问无线、存储或设备。静态零初始化，每次启动只使用一次；世代非零，输入来自同一 live host 执行者和单调毫秒时钟。不能拿此前扫描日志的 id1 或跨启动地址作为当前选择。

- 完整观察窗口 30000ms，窗口为 `[start, start+30000)`；截止后的报告不再合并。调用方应在独立期限内禁收、取消扫描、查询 inactive，且确认没有提前结束/host reset；在额外 1000ms 停止宽限内 seal。布尔参数只是调用方提供的证据，选择器本身不能验证 SDK 是否已停止。
- 整个窗口必须恰好一个相关协议候选。第二个 OTA 地址或同地址不同类型立即永久拒绝；不按 RSSI、首个/最后一个或多数报告选择。两个公开服务可为同一候选合并标记，不据此推导相机电源或身份。
- 仅 public/random OTA 类型；空地址、全零/全 ff、identity 地址类型拒绝。相关报告必须符合既有严格 31 字节 TLV 校验；任何格式错误报告粘性失败，包括无法判断归属的噪声报告。这可能保守拒绝嘈杂环境，不能解释为相机不支持。
- seal 时最后匹配报告距当前不超过 2000ms。take 要求当前世代、候选 id1、显式确认；距 seal 和最后匹配报告分别不超过 5000ms（都包含边界）。因此实际确认机会可能小于 5 秒。时钟回绕使用无符号差，倒退或过大跨度拒绝，不支持跨启动时钟。
- 未确认、错误 id/世代不会消费选择；到期的当前世代 take、失败、撤销和成功消费会清除私有候选表。迟到/旧世代报告、终态调用不能重启选择。同一对象不得重新 memset 复用。

对外 view 仅给出世代、临时编号和服务位，没有地址、名称、型号或“已验证”开关。view 没有时钟参数，只是待确认元数据，不证明仍新鲜；真正消费时重新核对期限。地址仅本次 RAM 使用，不日志、不持久化、不形成稳定相机身份。清零是状态清理，不作密码学擦除保证。

## Owner 交接

`io/gr4_gatt_target.c` 的 `frame_gr4_owner_prepare_from_target()` 先核对空指针、Owner 未使用和必要回调，再消费选择，显式复制 OTA 类型/地址给 Owner。prepare 不调用任何 SDK IO，不开始扫描、连接或读取。成功后选择不可再次使用；prepare 失败也不尝试其他目标、不自动重试。选择器、Owner 与后续激活必须同 host 串行执行、使用同一时钟，不可跨任务共享可变对象。

`confirmed=true` 只代表外部人工控制输入允许**一次未认证的公开身份只读尝试**，不是“已认证 GR IV”。未来入口必须绑定当次世代/id及新鲜的确认事件，不能固定 true、编译常量默认同意，或直接以 count==1 自动连接。人工确认附近仅本台相机也不是密码学身份核验；本轮没有记录新的目标选择/连接授权已获得。

Owner 仍只动态发现并读取 Manufacturer/Model/Firmware，结果为 `IDENTITY_UNVERIFIED`。不读取 Power/Operation Mode、不配对/SMP、不订阅 CCCD、不写 WLAN/ACK/拍摄/升级/删除。底层 Owner 另增加编译拒绝自动连接重试、隐私和 DTM 模式，不能依赖 SDK 默认值。

## 选择器阶段的设备集成缺口（历史）

现有扫描设备入口会停止并销毁自己的 SDK；现有无线 lifetime 要求 start 前已经准备 Owner，sync 时直接激活。二者不能简单串接：选择需要 live scan 的地址，销毁后不能复用，且现有 timer guard/global lifetime 每次启动只允许一次。也不能先消费目标再经过一次最长 15 秒初始化/同步，绕过 5 秒新鲜度。

下一步需要在**同一次 SDK 生命周期**中增加延迟激活：host 被动扫描，独立截止经 host 事件禁收/取消并取得 inactive 证据，再处理当次人工确认并立即交接/激活 Owner；总流程主任务另设外部期限。异常/取消必须先拒绝选择和 GATT，再沿既有 controller/timer/host/PMU 清理，保留工作任务仍引用的对象。还需实际入口 mock、Observer+Central 隔离配置、专用门禁和受控真机采证。

本阶段的合成测试只验证选择/交接契约，不能证明设备扫描取消、真实并发、地址新鲜度、相机型号/版本兼容、配对或 Gate A。当前无需重新开关机或操作相机。
