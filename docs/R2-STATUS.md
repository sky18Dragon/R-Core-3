# R2 现状

R2 在 R1 本地相框之上增加的功能、构建方式、验证结论与已知限制。逐轮证据见 [验证记录](VALIDATION.md)，后续任务见 [路线图](ROADMAP.md)，R1 交付见 [R1 交付说明](R1-RELEASE.md)。

## 构建

| 构建 | 命令 | 说明 |
| --- | --- | --- |
| 默认本地相框 | `python build.py --board read_pico --step firmware --read-pico-local-frame` | 常亮在线、不睡眠；含触摸、Wi-Fi 断线恢复、开机清理 |
| 电池睡眠变体 | 同上加 `--read-pico-pmu-sleep` | 单独输出目录 `build-read-pico-local-frame-sleep`；开机发 HOST_READY；网页可开关“电池睡眠” |

两者都使用已核验的 factory 分区表，只做 app-only 烧写（部署步骤见 [R1 交付说明](R1-RELEASE.md#3-部署只写应用分区)）。OTA 已于 2026-10-30 从项目移除，固件只经 USB 更新。

## 功能与验证

| 功能 | 行为 | 实机 |
| --- | --- | --- |
| 触摸换图 | 左滑下一张、右滑上一张（内存中 16 条历史）；最左触摸键上一张、最右下一张、中键不用；手动换图后轮播计时重置；`GET /api/touch` 诊断 | 通过（横屏 180° 校准）；刷屏期间触点不读取 |
| Wi-Fi 断线恢复 | 快速重试用尽后按 30 秒～10 分钟退避重连，不重启、不开热点 | 未实测（断网测试跳过） |
| 开机清理 | HTTP 启动前删除相册目录下精确命名的上传临时文件，每次至多 64 个 | 通过（删除 5 个、138KB） |
| 刷屏期间 SD 访问 | SD 访问与就绪检查等待板级锁最多 5 秒；刷屏取锁最多等 200ms | 通过（重叠上传 40/40、连续换图 100/100） |
| 电池睡眠（变体） | 电池供电且开关打开时，在轮播间隔经 PMU 软睡眠断电，闹钟唤醒换图；按键唤醒；接 USB 不睡；锁存后 5 秒未断电则取消并退避；持久事件日志 `GET /api/power` | 通过（闹钟唤醒 3 轮、按键唤醒、接 USB 不睡）；功耗未测 |
| 热点配网 | 已存 Wi-Fi 不可用时开设置热点 `PhotoFrame - XXXXX`（192.168.4.1） | 通过（两次换网络） |

## 已知限制

- 触摸坐标映射只在横屏、旋转 180° 下实测；其他方向按对称推导。
- 电池/USB 判定依据 PMU 充电状态与充电脚，实测两种状态正确；充满后接 USB 判为“未知”，不会睡眠。
- 睡眠期间网页不可用，ping 可能仍被网络侧代答，不能据此判断设备在线；以 `/api/power` 事件日志为准。
- 未验证：Wi-Fi 断网恢复、断电冷启动、满卡、功耗与续航、PMU 复位后闹钟丢失的恢复、数日长稳。
- 未开发：URL 图源完整链路、配置并发审查、大图性能、远端 CI。
